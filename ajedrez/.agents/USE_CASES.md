# Casos de Uso — Ajedrez

## CU-01: Partida de Ajedrez Clásico (`index.html`)
- **Actor:** Estudiante / Jugador.
- **Descripción:** Permite jugar una partida de ajedrez clásico sobre el tablero interactivo validando las reglas oficiales del juego (movimientos por pieza, jaque, jaque mate, ahogado, enroque, captura al paso y coronación).

## CU-02: Modo Entrenamiento Progresivo (`index.html`)
- **Actor:** Estudiante.
- **Descripción:** El usuario selecciona una de las 4 pestañas de entrenamiento (**Piezas**, **Aperturas**, **Tácticas**, **Mates**), elige un ejercicio o apertura clasificada por nivel (*Principiante*, *Intermedio*, *Avanzado*) y utiliza el reproductor paso a paso (`⏮ ‹ ▶ › ⏭`) para recorrer la secuencia algebraica sobre el tablero.
- **Síntesis de voz:** Mediante el botón **🔊 Escuchar explicación**, el sistema lee en voz alta el campo `descripcion` asociado al ítem seleccionado.

## CU-03: Juego en Variantes Reconocidas (`variantes.html`)
- **Actor:** Estudiante / Jugador.
- **Descripción:** Permite explorar y jugar variantes reconocidas del ajedrez con sus reglas y configuraciones específicas de tablero.

## CU-04: Juego en Variantes Rudo (`variantes-rudo.html`)
- **Actor:** Estudiante / Jugador.
- **Descripción:** Permite jugar variantes propias y experimentales diseñadas para el proyecto.

## CU-05: Navegación del Curso de Ajedrez (`curso.html`)
- **Actor:** Estudiante.
- **Descripción:** Interfaz de acceso y recorrido estructurado del curso de ajedrez por niveles y clases.
