# Touch Typing (`dactilografia`)
Interactive touch-typing speed/accuracy trainer in `platon6/sitio-web/dactilografia/`.
- **Core features:** Progressive level selector (`ASDF JKLÑ` to complex text/code), error/latency smart suggestion engine, color-coded finger visual keyboard, and no-`Enter` requirement on the last line of each lesson.
- **Stack:** Pure Vanilla JS (WPM, net/gross accuracy, per-char latency) and CSS transitions (green = hit, red = error).
