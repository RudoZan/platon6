Instalar tu asistente de IA

En este taller usamos Visual Studio Code (VS Code) con el plugin de GitHub Copilot como referencia: es gratis, funciona igual en Windows y Mac, y es el editor más usado en el mundo, así que lo que aprendas acá te sirve para cualquier otro proyecto. Si ya usas otra herramienta de la lista anterior, estos mismos pasos se adaptan fácilmente.

Instalar Visual Studio Code

  1. Entra a code.visualstudio.com desde tu navegador.
  2. Descarga el instalador para tu sistema operativo: la página detecta automáticamente si usas Windows o Mac y te muestra el botón correcto.
  3. Abre el archivo descargado y sigue los pasos del instalador (en Windows es un .exe; en Mac es un .zip que deja la aplicación lista para arrastrar a la carpeta Aplicaciones).
  4. Abre Visual Studio Code una vez instalado, para confirmar que quedó funcionando.

Instalar el plugin de GitHub Copilot

Para usar Copilot necesitas una cuenta de GitHub. Si todavía no tienes una, créala ahora mismo en github.com — es gratis y toma un par de minutos (más adelante, en el Módulo 7, vas a usar esa misma cuenta para publicar tu sitio).

  1. Abre el panel de extensiones en VS Code: es el ícono de cuadrados en la barra lateral izquierda (o Ctrl+Shift+X en Windows, Cmd+Shift+X en Mac).
  2. Busca "GitHub Copilot" en el buscador de extensiones.
  3. Haz clic en "Install" en la extensión oficial de GitHub (verifica que diga "GitHub Copilot" y muestre a GitHub como autor).
  4. Inicia sesión con tu cuenta de GitHub cuando VS Code te lo pida: te va a abrir el navegador para autorizar el acceso.
  5. Confirma que quedó activo abriendo un archivo de código: deberías empezar a ver sugerencias de Copilot en gris mientras escribes.
Recuerda

Copilot requiere una cuenta de GitHub y, para usarlo más allá del período de prueba, un plan pago o el plan gratuito con cupo limitado. Si ya tienes una cuenta de GitHub de estudiante, revisa si calificas para el GitHub Student Developer Pack, que incluye Copilot gratis.

Si algo del proceso de instalación falla o no coincide exactamente con lo descrito acá (las páginas de descarga cambian con el tiempo), pídele ayuda a cualquier IA: cuéntale en qué paso estás y qué ves en pantalla.
