# Interactive Digital Resources Workshop (`tallerRecursosEducativos`)
Course in `platon6/sitio-web/tallerRecursosEducativos/` training teachers (mainly Math) to build educational web apps using AI.
- **Modules:** `modulo-01-recursos-educativos-digitales/`, `modulo-02-ias-y-cursor/`, `modulo-03-sitio-html-js/`, `modulo-05-imagenes-multimedia/`, `modulo-07-subir-a-github/`.
- **Rule:** Keep all examples in simple, readable Vanilla HTML/CSS/JS suitable as live demos for non-programmer teachers.
