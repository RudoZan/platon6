# AGENTS.md — Taller de Recursos Digitales Interactivos

## 🎯 Propósito y Filosofía Pedagógica
Curso interactivo estructurado para capacitar a docentes (con foco principal en Matemática) en la creación autónoma de software y recursos didácticos mediante Inteligencia Artificial.
* **Propósito:** Derribar las barreras de entrada al desarrollo de software educativo sin pretender transformar a los docentes en ingenieros de software o programadores tradicionales.
* **Enfoque Técnico:** Transmitir nociones esenciales de arquitectura web (HTML/CSS/JS), ciclo de vida del software, diseño por componentes y buenas prácticas para formular prompts técnicos y depurar problemas comunes.

## 📁 Estructura del Taller
El curso está dividido en módulos formativos secuenciales:
* `modulo-01-recursos-educativos-digitales/`: ¿Qué son y comparación de tipos de recursos.
* `modulo-02-ias-y-cursor/`: Configuración y trabajo asistido por IA (Cursor, LLMs).
* `modulo-03-sitio-html-js/`: Fundamentos prácticos de construcción de páginas y dinamismo.
* `modulo-05-imagenes-multimedia/`: Integración de recursos visuales y auditivos.
* `modulo-07-subir-a-github/`: Publicación y despliegue gratuito mediante GitHub Pages.

## 🛠️ Reglas de Desarrollo
* Los ejemplos y módulos deben servir como demostración en vivo del código que los propios profesores pueden construir (Vanilla JS, CSS intuitivo y HTML semántico).
